# Learning TypeScript (JavaScript workspace)

This repository contains simple JavaScript example files used for learning purposes.

Contents:
- `1stJSCode.JS` — first JavaScript example file.
- `JS/` — folder with `Ramya.js` and `welcome.js` examples.
- `Javascript Concepts/` — placeholder folder.

How to run

1. Ensure you have Node.js installed.
2. From the project root run:

```ps1
node 1stJSCode.JS
```

Notes

- This repo was initialized locally and pushed to https://github.com/ramyapolath/Learningtypescript.git
- `.gitignore` excludes common Node, editor, and OS files.
